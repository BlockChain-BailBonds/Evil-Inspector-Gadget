# Evil Inspector 918 Flipper FAP

External FAP for full-duplex 918 Inspector telemetry over the established ESP32-S3 UART1 connection: S3 RX GPIO3 from Flipper TX and S3 TX GPIO7 to Flipper RX, with 3.3V signaling and common ground. Never attach Flipper TX to S3 GPIO44, which is unrelated to the established bridge. Build using the official matching Flipper `ufbt` SDK: `cd inspector_gadget && ufbt`. Do not install the FAP on the S3; it belongs on the Flipper microSD `/ext/apps/GPIO/`. The FAP supports explicit PING, STATUS, HOME, passive WIFI scan, and passive BLE scan commands when its UART monitor is open; it never sends Flipper RF/IR transmissions.
