# Evil Inspector 918 Flipper FAP

External FAP for full-duplex 918 Inspector telemetry and fixed UART command transmission over independent ESP32-S3 UART1 (RX GPIO3 / TX GPIO48), with 3.3V GPIO and shared ground. GPIO3 strapping and GPIO48 onboard LED loading must be electrically validated. Never attach Flipper TX to S3 GPIO44, which shares the CH340 USB console. See `README-FLIPPER-DUPLEX.md` at repo root for the proposed wiring and verification gate. Build using the official matching Flipper `ufbt` SDK: `cd inspector_gadget && ufbt`. Do not install the FAP on the S3; it belongs on the Flipper microSD `/ext/apps/GPIO/`. The FAP supports explicit PING, STATUS, HOME, passive WIFI scan, and passive BLE scan commands when its UART monitor is open; it never sends Flipper RF/IR transmissions.
